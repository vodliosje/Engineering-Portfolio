# Asset and Ownership Inventory

Status values:

- **READY** — safe and sufficiently supported for current public use.
- **VERIFY** — claim/artifact exists but needs a reproducible check or external confirmation.
- **BUILD** — useful evidence does not yet exist and should be created.
- **PRIVATE** — must remain private; only sanitized/synthetic evidence should be published.
- **FIX** — a known issue should be corrected before the artifact is promoted.
