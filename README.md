## Evidence Principles

This repository follows several rules:

1. Claims should be supported by reproducible or inspectable evidence where possible.
2. Team contributions should not be presented as individual work.
3. Private data, credentials, API keys, and sensitive information must not be published.
4. Metrics should be documented with their methodology and source.
5. Unsupported claims should be revised or removed rather than reverse-engineered to match a Resume statement.
